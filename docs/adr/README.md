# Architecture decision records

One-way decisions only: hard to reverse, surprising without context, and the result of a real trade-off.
Files are `0001-slug.md`, `0002-slug.md`, numbered in order. Format: `.claude/skills/domain-modeling/ADR-FORMAT.md`.

Always an ADR here: an engine that sends audio off the machine, the storage format of the testing log, anything
about consent or retention.
